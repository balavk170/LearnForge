# 3-minute LearnForge demo

1. **Problem / hook (20 sec):** “Students can repeat definitions, but often can’t connect an idea to a real problem. LearnForge turns one topic into four learning moves.”
2. **Landing / dashboard (25 sec):** Show the learning cycle, then open the dashboard and point out streak, mastery, skill breakdown, recent activity, and personalized next steps.
3. **Generate (25 sec):** Open Learning Studio, choose Beginner, and build the Python Loops learning path. Explain that the response is labeled AI-personalized or demo content depending on provider availability.
4. **Understand (30 sec):** Walk through the plain-language explanation, analogy, code example, and common mistake. Mark understanding to update session mastery.
5. **Connect (25 sec):** Click Lists and Conditions in the interactive map. Explain why loops are useful with each idea.
6. **Apply (40 sec):** Read the shopping challenge. Try an approach before revealing progressive hints. Submit a solution/approach and inspect rubric-like feedback.
7. **Think / progress (30 sec):** Answer the deeper question, submit reasoning, view feedback, then show that mastery and dashboard activity have updated.
8. **Close (5 sec):** “Not another chatbot: LearnForge connects explanation, concept relationships, application, reflection, and measurable progress.”

For an offline event, leave `AI_PROVIDER=demo`; the experience is fully functional without credentials or network access to an LLM.
